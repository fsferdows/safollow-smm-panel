2. Add Order

Place a new single order for any service.

Parameter Type Description
key String Your unique API Key
action String add
service Integer Service ID (e.g. 2374)
link String Target URL (profile, post, channel, video)
quantity Integer Needed quantity (must respect min and max)
Example Response: 
{
  "order": 149204
}

3. Order Status

Check the real-time fulfillment status of one or multiple orders.

Parameter Type Description
key String Your unique API Key
action String status
order Integer Single order ID (e.g. 149204)
orders String (Optional) Comma-separated order IDs: 149204,149205
Example Response (Single Order): 
{
  "charge": "0.1851",
  "start_count": "1520",

Python Integration Example

import requests

API_URL = "http://localhost:3000/api/v2"
API_KEY = "YOUR_API_KEY_HERE"

# 1. Check Balance
res = requests.post(API_URL, data={"key": API_KEY, "action": "balance"})
print("Balance:", res.json())

# 2. Add an Order
order_data = {
    "key": API_KEY,
    "action": "add",
    "service": 2374,
    "link": "https://www.facebook.com/example/posts/123",
    "quantity": 1000
}
order_res = requests.post(API_URL, data=order_data).json()
print("Order placed:", order_res)

# 3. Check Order Status
if "order" in order_res:
    status_res = requests.post(API_URL, data={
        "key": API_KEY,
        "action": "status",
        "order": order_res["order"]
    }).json()
    print("Status:", status_res)
